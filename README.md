# 🐾 Котеус: Мир из снов (Jam Project UTMN)

Прототип 2D-платформера на **Godot Engine (GDScript)**, созданный в рамках университетского хакатона «Котоджем ТюмГУ».

## 🍇 Концепция и сеттинг
Студент-маскот засыпает после бессонной ночи над дипломом, и во сне кампус вуза превращается в парящие острова из уличных скамеек, по которым разлетелись страницы его работы.

## ✅ Что реализовано в текущей сборке (MVP v0.1.0)
* **Базовый игровой цикл:** интерактивный стартовый экран, прохождение уровня и финал с динамическим расчетом итоговой оценки в зачетной книжке.
* **Структура и стабильность (Godot 4.6.3):** логика разделена на независимые скрипты и сцены, консоль отладки без ошибок и предупреждений (`0 Errors, 0 Warnings`).
* **Кроссплатформенный Web-экспорт:** сборка в однопоточном режиме (`Single-Threaded`, `gl_compatibility`) для стабильного запуска в браузерах на ПК и смартфонах (включая мобильный Safari).

## 🛠 Статус разработки
Проект находится в активной разработке: базовое ядро игры готово и протестировано, в дальнейшем планируется доработка механик, исправление мелких визуальных багов и расширение контента.
